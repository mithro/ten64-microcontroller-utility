ten64-controller apt repository

Debian package of the Traverse Ten64 microcontroller utility: a command-line tool (ten64-controller) that talks to the Ten64's LPC804 board-management microcontroller over I2C — read firmware version and serial, system control state (ATX power, boot source, reset button), inspect the firmware image banks, and install microcontroller firmware. arm64 only (Ten64 hardware). Source: github.com/mithro/ten64-microcontroller-utility.

Each suite is its own flat repository, so the source line must name one (trixie/ or sid/) and keep the trailing ./ — the repository root carries no Packages file. Pick the suite matching your system (. /etc/os-release; echo $VERSION_CODENAME).

Setup (Ten64, Debian trixie arm64)

sudo install -d -m0755 /etc/apt/keyrings
curl -fsSL https://mithro.github.io/ten64-microcontroller-utility/ten64-controller.gpg \
  | sudo tee /etc/apt/keyrings/ten64-controller.gpg > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/ten64-controller.gpg] https://mithro.github.io/ten64-microcontroller-utility/trixie/ ./" \
  | sudo tee /etc/apt/sources.list.d/ten64-controller.list

sudo apt update
sudo apt install ten64-controller
